# P. Blöndal ehf.

Vefsíða P. Blöndal ehf., gröfuþjónusta og jarðvinna á höfuðborgarsvæðinu.

- `index.html`: síðan sjálf
- `logo.png`, `logo-ljost.png`: merki fyrir ljóst og dökkt útlit

## Birting með GitHub Pages

Settings → Pages → Source: *Deploy from a branch*, branch `main`, mappa `/ (root)`.

## Tilboðsform

Fyrirspurnir úr forminu eru sendar á petur@pblondal.is í gegnum FormSubmit (formsubmit.co).
Við fyrstu sendingu kemur staðfestingarpóstur á petur@pblondal.is sem þarf að smella á einu sinni áður en fyrirspurnir fara að berast.
